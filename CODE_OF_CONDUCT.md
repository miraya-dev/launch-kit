# Code of conduct

launch-kit follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short:

- Be kind and patient. People join from many countries and write in English, Arabic or French; assume good intent.
- Critique ideas and code, never people.
- No harassment, insults, sexual language or imagery, or personal attacks, in any space of this project: issues, pull requests, discussions and anywhere you represent the project.
- Don't publish anyone's private information.

## Reporting

If someone breaks these rules, tell the maintainer, Moncef El hirech ([EL-MO-DEV](https://github.com/EL-MO-DEV) on GitHub). To report privately, open an issue that only asks for a private channel, without details, and we'll reply there. You can also use GitHub's **Report content** option on any comment or issue.

Reports are handled confidentially. The maintainer may edit or remove comments, close issues and pull requests, and block people who break these rules, as described in the Covenant's enforcement guidelines.
