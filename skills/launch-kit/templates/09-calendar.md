## Post-launch checklist

- [ ] Answer every new issue, pull request and question within 24 hours
- [ ] Label and triage: `bug`, `enhancement`, `good first issue`, `question`
- [ ] Thank contributors by name in the release notes
- [ ] Cut a release with the launch-week fixes: `gh release create {{version}} --generate-notes`
- [ ] Add the most-asked questions to a README FAQ
- [ ] Reply in the original threads when requested features ship
- [ ] Record metrics before they expire (Insights → Traffic keeps 14 days)
- [ ] Write down what you learned: it's your next article
