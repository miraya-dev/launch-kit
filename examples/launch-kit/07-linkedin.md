Before launching launch-kit, I ran it on its own repo. It flagged three things still missing: no release tag, no CHANGELOG, and a README link to a folder that didn't exist yet.

That's what it's for. Building a project is one job; launching it is another. And every community has its own rules about how you can talk about your own work.

So I built launch-kit at Miraya, my small software studio. It's a free, open-source Claude Code skill: you point it at a repository and it writes a launch pack as markdown files.

What you get:
- Positioning, with a fair comparison to alternatives
- A GitHub checklist with ready-to-paste README edits
- Drafts for Hacker News, Reddit, Product Hunt, X, LinkedIn and dev.to, each shaped by that community's rules
- A 14-day launch calendar

It never posts anything. Every draft says you're the maker, it won't suggest vote exchanges or fake accounts, and you rewrite everything in your own words before posting. This post started as one of those drafts.
